# gost-bot

Telegram-бот, который оформляет студенческие работы Word (.docx) по ГОСТ 7.32-2017
или по требованиям вуза (сейчас — НИТУ МИСИС). Меняется только оформление: шрифты,
отступы, заголовки, подписи, списки, нумерация страниц, оглавление. Текст остаётся слово в слово.

**Как это выглядит для пользователя:** присылает файл → бесплатно получает отчёт о нарушениях →
оплачивает через СБП (ЮKassa) → получает оформленный файл и отчёт о том, что изменено
и что стоит проверить вручную.

**Гарантии:** файл выдаётся, только если автоматическая проверка подтвердила, что текст
не изменился, а оформление соответствует профилю. Иначе — автоматический возврат денег.

## Стек

Python 3.12 · aiogram 3 · arq + Redis · PostgreSQL 16 · python-docx/lxml ·
LibreOffice (headless) · ЮKassa (СБП) · OpenAI `gpt-6-luna` (опционально) · Docker Compose.

Веб-сервера нет: бот сам опрашивает Telegram и ЮKassa, поэтому не нужны домен, HTTPS
и открытые порты — достаточно любого VPS.

## Быстрый старт

```bash
cp .env.example .env        # заполнить токен бота, пароль БД, ключи ЮKassa, реквизиты
docker compose up -d --build
# проверка: написать боту /start
```

## Структура

```text
app/core/       ядро: разбор docx, классификация, сборка, проверки (без бота и БД)
app/bot/        Telegram-бот           app/workers/   фоновая обработка (arq)
app/payments/   ЮKassa                 app/services/  сценарий заказа, юр. документы
app/profiles/   профили оформления     app/db/        модели и миграции
docker/         Dockerfile, compose
docs/           гайд, исходные требования, юридические документы
tests/          unit и интеграционные тесты, корпус (не в git)
```
