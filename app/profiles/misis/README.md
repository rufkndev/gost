# Профиль «НИТУ МИСИС»

Источник требований: `docs/source/гостВУЗ.docx` (методичка кафедры бизнес-информатики и систем управления производством).
Где методичка молчит, значения взяты из `docs/source/ГОСТ_7.32-2017.pdf`.

Метка у каждого значения в `profile.yaml` показывает его происхождение: `[ВУЗ: раздел]`, `[ГОСТ п.]`, `[SPEC]` или `[?]` (допущение).
Решения владельца по профилю и допущения описаны в `docs/GUIDE.md`.

Стили строятся из `profile.yaml` при каждой обработке. `template.docx` — только для просмотра в Word: `python -m app.core.cli build-template misis`.
