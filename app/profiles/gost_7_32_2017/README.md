# Профиль «ГОСТ 7.32-2017»

Источник требований: `docs/source/ГОСТ_7.32-2017.pdf`, раздел 6 «Правила оформления отчета».

Метка у каждого значения в `profile.yaml` показывает его происхождение: `[ГОСТ п.]`, `[SPEC]` или `[?]` (допущение).
Расхождения со spec (`docs/source/spec.md`) и решения владельца описаны в `docs/GUIDE.md`.

Стили строятся из `profile.yaml` при каждой обработке. `template.docx` — только для просмотра в Word: `python -m app.core.cli build-template gost_7_32_2017`.
